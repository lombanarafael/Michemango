# 🥭 MicheMango

## Descripción

MicheMango es una página web creada para promocionar y vender miche de mango. Su objetivo es ofrecer a los clientes una forma sencilla de conocer los productos, los precios y la información del emprendimiento.

## Objetivos

- Dar a conocer la marca MicheMango.
- Mostrar el catálogo de productos.
- Facilitar el contacto con los clientes.
- Impulsar las ventas del emprendimiento.

## Cómo iniciar el backend

Desde la carpeta `backend`, instala las dependencias y ejecuta el servidor:

```bash
npm install
npm start
```

El servidor estará disponible en `http://localhost:3000` y los productos en
`http://localhost:3000/api/productos`.

También puedes abrir `http://localhost:3000/index.html` para ver el frontend.
La página solicita los productos al backend usando JavaScript y los muestra
automáticamente.
